✏️ Pencil Hack

사진이나 일러스트를 업로드하면 브라우저 안에서 바로 연필 선화(라인아트) 스타일로 바꿔주는 무료 도구입니다. 파일을 서버로 전송하지 않고 내 컴퓨터에서만 처리되기 때문에 개인 사진도 안심하고 사용할 수 있습니다.

이미지를 드래그하거나 클릭해서 업로드
* 모든 처리는 Canvas API로 브라우저 안에서만 실행됩니다.
* Threshold를 낮출수록 세밀한 선이 더 많이 잡힙니다.
* 결과가 너무 지저분하면 Blur를 올려보세요.

원본

이미지 없음

선화 결과 (투명 배경 PNG)

변환 대기중

SVG 코드

아래 코드를 복사해서 웹사이트, 디자인 툴 등에 벡터 그래픽으로 바로 사용할 수 있습니다.

선화 변환기란?

선화(라인아트, Line Art)는 사진이나 그림의 색상과 명암을 제거하고 윤곽선만 남긴 스타일을 말합니다. 만화, 웹툰 밑그림, 컬러링북 도안, 자수 패턴, 스티커 제작 등 다양한 분야에서 활용됩니다. 이 도구는 Sobel 엣지 검출과 DoG(Difference of Gaussian) 알고리즘을 이용해 이미지의 경계선을 자동으로 추출하고, 이를 투명 배경 PNG 형태의 깔끔한 선화로 변환해줍니다.

주요 기능

🔒 완전한 로컬 처리

이미지가 서버로 전송되지 않고 브라우저 Canvas API에서만 처리되어 개인정보와 저작권 이미지 모두 안전합니다.

🎚️ 세밀한 조절

엣지 감도, 선 굵기, 대비(감마)를 슬라이더로 실시간 조정하며 원하는 결과물을 만들 수 있습니다.

🎨 선 색상 커스텀

기본 검정 선 외에도 원하는 색상을 지정해 컬러 라인아트를 만들 수 있습니다.

🖼️ 투명 배경 PNG

배경이 완전히 투명하게 저장되어 다른 디자인 위에 바로 합성해서 사용할 수 있습니다.

사용 방법

  1. 변환하고 싶은 이미지를 업로드 영역에 드래그하거나 클릭해서 선택합니다.
  2. 필요에 따라 엣지 감도, 선 굵기, 대비, 모드(Sobel/DoG), 선 색상을 조절합니다.
  3. "변환하기" 버튼을 눌러 결과를 확인합니다.
  4. 마음에 드는 결과가 나오면 "다운로드" 버튼으로 투명 배경 PNG 파일을 저장합니다.

이럴 때 활용해보세요

컬러링북 도안 제작

사진을 선화로 바꿔서 직접 색칠할 수 있는 나만의 컬러링 페이지를 만들 수 있습니다.

그림 연습용 밑그림

따라 그리기 연습이나 트레이싱용 참고 자료로 활용하기 좋습니다.

로고·스티커 디자인

투명 배경 선화를 다른 이미지나 배경 위에 겹쳐 스티커, 각인 도안 등으로 응용할 수 있습니다.

자수·각인 패턴

단순한 선으로 이루어진 결과물이라 자수나 레이저 각인용 패턴 제작에도 활용됩니다.

자주 묻는 질문

업로드한 사진이 외부 서버에 저장되나요?

아니요. 이 도구는 모든 이미지 처리를 브라우저 안의 Canvas API로 수행하며, 파일을 어떤 서버로도 전송하지 않습니다. 페이지를 닫으면 처리된 데이터도 함께 사라집니다.

어떤 이미지가 가장 잘 변환되나요?

윤곽이 뚜렷한 인물 일러스트, 캐릭터, 사물 사진이 가장 깔끔하게 변환됩니다. 배경이 복잡하거나 대비가 낮은 사진은 Threshold와 Blur 값을 조절해 원하는 결과를 찾아보세요.

Sobel 모드와 DoG 모드의 차이는 무엇인가요?

Sobel 모드는 경계선을 뚜렷하고 균일하게 추출해 깔끔한 만화체 선화에 적합하고, DoG 모드는 좀 더 부드럽고 손그림 같은 스케치 느낌의 선을 만들어줍니다.

결과물을 상업적으로 사용해도 되나요?

변환된 결과물의 저작권은 원본 이미지의 저작권 상태를 따릅니다. 본인이 저작권을 보유했거나 사용 권한이 있는 이미지에만 이 도구를 사용해주세요.
